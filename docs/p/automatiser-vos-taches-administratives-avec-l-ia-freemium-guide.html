Introduction

Vous passez trop de temps à gérer des factures, des relances ou à planifier vos réunions ? La plupart de ces activités sont répétitives et peuvent être confiées à des outils d’intelligence artificielle gratuits ou en version freemium. Ce guide montre comment bâtir, sans budget, un système d’automatisation qui libère des heures chaque semaine.

1. Cartographier les tâches administratives

Avant de choisir un outil, listez les actions qui vous font perdre du temps. Exemple de tableau :

  • Facturation : création du devis, envoi, suivi du paiement.
  • Relance client : email de rappel, mise à jour du statut.
  • Gestion d’agenda : prise de rendez‑vous, envoi de confirmations.
  • Reporting : agrégation des KPI (revenus, heures facturées, dépenses).

Pour chaque ligne, notez la fréquence (quotidienne, hebdomadaire, mensuelle) et le format actuel (Google Sheet, Outlook, PDF). Cette cartographie vous permet de cibler les points où l’IA peut intervenir.

3. Créer un workflow automatisé

Voici le schéma logique à reproduire avec Zapier (ou Integromat) :

  1. Déclencheur : ajout d’une ligne dans Google Sheet « Factures à envoyer ».
  2. Action 1 : appeler l’API de ChatGPT pour générer le texte du devis à partir des champs (client, service, tarif).
  3. Action 2 : créer un PDF avec PDFMonkey (plan gratuit) et l’enregistrer dans Google Drive.
  4. Action 3 : envoyer le PDF par Mailmeteor à l’adresse du client, avec copie à votre adresse.
  5. Action 4 : créer une tâche dans Notion « Suivi paiement » avec date d’échéance.
  6. Action 5 : si la date d’échéance dépasse 7 jours, déclencher un email de relance via Mailmeteor.

Le même principe s’applique à la prise de rendez‑vous : le formulaire Calendly crée automatiquement un événement Google Calendar et une entrée dans Notion.

4. Exemple concret pas à pas (freelance en design graphique)

Étape 1 – Préparer la feuille de facturation

  1. Ouvrez Google Sheet et créez les colonnes : Client, Service, Tarif, Date, Statut.
  2. Partagez le tableau avec votre compte Zapier.

Étape 2 – Configurer le prompt ChatGPT

Dans Zapier, ajoutez une action Webhooks – POST :

{
  "model": "gpt-3.5-turbo",
  "messages": [{"role": "user", "content": "Rédige un devis professionnel pour {{Client}} concernant {{Service}} au tarif de {{Tarif}} €."}]
}

Le texte retourné sera inséré dans le modèle de PDF.

Étape 3 – Générer le PDF

Utilisez PDFMonkey : choisissez un modèle simple (logo, tableau, mentions légales) et mappez les variables du texte généré.

Étape 4 – Envoi et suivi

Configurez Mailmeteor pour prendre le PDF en pièce jointe et envoyer l’email : « Bonjour {{Client}}, voici votre devis… ». Zapier crée ensuite une entrée « En attente de paiement » dans Notion.

Étape 5 – Relance automatisée

Dans Notion, ajoutez une vue filtrée « Relances à faire ». Zapier vérifie quotidiennement la vue ; si la date dépasse 7 jours, il envoie une relance standard.

Étape 6 – Centraliser le tableau de bord

Dans Notion, créez une page « Dashboard administratif » affichant : - Le nombre de factures émises. - Le total des montants en attente. - Les tâches de relance du jour. Ce tableau de bord vous donne une vision claire sans ouvrir plusieurs outils.

5. Astuces pour garder le contrôle et éviter la surcharge

  • Limiter le nombre de tâches Zapier : commencez avec les processus les plus chronophages (facturation) puis ajoutez d’autres automatisations.
  • Documenter chaque zap : ajoutez une description dans Zapier et dans Notion pour que vous ou un futur collaborateur compreniez le flux.
  • Tester sur un échantillon : avant de lancer le workflow sur tous vos clients, faites un test avec un faux client pour vérifier le rendu du PDF et la délivrabilité des emails.
  • Utiliser les notifications : activez les alertes Zapier par email en cas d’erreur afin d’intervenir rapidement.
  • Faire un point mensuel : exportez les données de Notion vers Google Data Studio (plan gratuit) pour visualiser l’évolution de vos encaissements.
